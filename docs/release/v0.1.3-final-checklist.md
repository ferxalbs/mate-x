# MaTE X v0.1.3 Final Release Checklist

Release owner completes this checklist against one exact commit and attaches workflow-generated release evidence. Old v0.1.2 results do not count.

## Commit and source

- [ ] Candidate branch contains only intended v0.1.3 release changes.
- [ ] Exact candidate commit SHA recorded.
- [ ] Clean checkout resolves to that SHA.
- [ ] `package.json` version is `0.1.3`.
- [ ] Bun version is pinned to `1.3.14` locally and in GitHub Actions.
- [ ] `git diff --check` passes.

## Required verification

- [ ] `bun install --frozen-lockfile`
- [ ] `bun run check:deprecated`
- [ ] `bun run lint`
- [ ] `bun run typecheck`
- [ ] `bun run test:all`
- [ ] `bun run verify`
- [ ] `bun run verify:release`
- [ ] Exact test pass/fail count copied from current run.

## macOS Intel x64

- [ ] Native Intel runner confirmed.
- [ ] Native dependencies load.
- [ ] Package succeeds.
- [ ] ASAR purity passes with `--require-asar`.
- [ ] Packaged E2E passes, including black-box startup.
- [ ] DMG/ZIP distributables exist.
- [ ] SHA-256 checksums exist and re-verify.

## macOS Apple Silicon arm64

- [ ] Native Apple Silicon runner confirmed.
- [ ] Native dependencies load.
- [ ] Package succeeds.
- [ ] ASAR purity passes with `--require-asar`.
- [ ] Packaged E2E passes, including black-box startup.
- [ ] DMG/ZIP distributables exist.
- [ ] SHA-256 checksums exist and re-verify.

## Distribution posture

- [ ] Artifact and release text say **Unsigned macOS Public Preview**.
- [ ] Windows and Linux artifacts are absent.
- [ ] GitHub Release remains draft and prerelease.
- [ ] Publication input is explicit; automatic tag creation is impossible.
- [ ] Existing `v0.1.3` tag, if publishing, points to exact qualified SHA.
- [ ] Native silent auto-update remains disabled.
- [ ] Manual updater opens only official GitHub Release URL.
- [ ] Gatekeeper guidance uses Apple UI and does not bypass security controls.

## Privacy and product truth

- [ ] Fresh-install telemetry default is off.
- [ ] No remote telemetry client initializes before opt-in.
- [ ] Settings explain collected categories, exclusions, disable path, and no function impact.
- [ ] README describes agent-independent harness/Trust Engine, behavior-policy separation, evidence-driven outcomes, and explicit Git gates.
- [ ] README contains no unsupported performance, security, stability, or GA claims.

## Evidence and decision

- [ ] Workflow-generated evidence names exact SHA and run URL.
- [ ] Evidence lists commands and exact results.
- [ ] Evidence lists artifact names, architectures, checksums, packaged E2E, ASAR purity, test count, and unresolved risks.
- [ ] Rollback procedure reviewed.
- [ ] Final verdict recorded as `GO`, `CONDITIONAL GO`, or `NO-GO` using evidence from exact SHA.
