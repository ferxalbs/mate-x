# MaTE X v0.1.3 — Unsigned macOS Public Preview

MaTE X v0.1.3 is an unsigned Public Preview for macOS Intel and Apple Silicon. It is not a stable or generally available release.

> MaTE X is the execution and trust runtime for AI software agents. Connect the agent you prefer; MaTE X governs what it can do, records what actually happened, validates the result, and produces evidence you can trust.

## What changed

### Agent-independent Trust Engine

- Positions MaTE X as engineering harness around agents and SDK-backed runtimes, not replacement IDE or generic chatbot.
- Keeps `EngineeringTask` as canonical workflow authority.
- Defines Review, Plan, and Execute as agent behavior while Workspace Policy independently controls read-only, approval-required, and permitted changes.
- Keeps sensitive operations and Git commit/push explicitly gated.
- Uses typed runtime outcomes and executed evidence, not assistant prose, to determine success.

### Release integrity

- Pins Bun `1.3.14` in release workflow.
- Runs locked install, deprecation scan, lint, typecheck, all tests, full verification, release verification, and patch whitespace checks against exact commit.
- Qualifies separate native macOS Intel x64 and Apple Silicon arm64 packages.
- Fails closed on native dependency loading, package creation, ASAR purity, packaged E2E, or checksum generation.
- Uploads SHA-256 manifests and exact-run release evidence.
- Keeps release publication manual, draft, prerelease, and dependent on existing exact `v0.1.3` tag.
- Produces no Windows or Linux v0.1.3 public artifacts.

### Privacy and updates

- Product telemetry is off by default and starts remote delivery only after opt-in.
- Telemetry remains schema-restricted, allowlisted, sanitized, and best-effort.
- Prompts, responses, source code, repository paths or identity, commands, credentials, secrets, billing data, and raw stack traces are excluded.
- Manual updater now detects non-draft Public Preview releases and opens only official GitHub Release pages.
- Native silent auto-update stays disabled for unsigned artifacts.

### Runtime and performance work

v0.1.3 includes startup deferral and parallelization, lazy module loading, bounded concurrency, semantic context management, power-aware scheduling, and native macOS dependency qualification. These are engineering changes, not unsupported blanket speed claims; exact release evidence records checks that ran.

## Install

1. Download artifact matching Mac architecture from official [GitHub Releases](https://github.com/ferxalbs/mate-x/releases).
2. Verify SHA-256 against published manifest:

   ```bash
   shasum -a 256 "/path/to/MaTE X artifact"
   ```

3. Move MaTE X to Applications.
4. If Gatekeeper blocks first launch, use Finder Control-click → **Open**, or **System Settings → Privacy & Security → Open Anyway** after blocked launch.
5. Confirm approval only when download came from official repository and checksum matches.

Do not disable Gatekeeper, remove quarantine metadata with `xattr`, or lower macOS security settings.

## Updates

v0.1.3 checks GitHub Releases and opens official download page when newer version exists. It does not download or install updates silently.
