# MaTE X v0.1.3 Known Issues

## Release status

v0.1.3 is unsigned macOS Public Preview. Risks below are release constraints, not hidden qualifications.

## Unsigned and not notarized

Apple Developer signing and notarization credentials are unavailable for this release.

Impact:

- Gatekeeper may block first launch.
- macOS does not show identified-developer or notarization trust.
- Native silent auto-update is disabled.

Safe installation:

- Verify published SHA-256 checksum.
- Use Finder Control-click → **Open**, or **System Settings → Privacy & Security → Open Anyway** after blocked launch.
- Do not disable Gatekeeper, use `xattr` to strip quarantine, or lower macOS security controls.

## Manual updates only

**Check for Updates** opens official GitHub Releases when newer non-draft release exists. User downloads, verifies, and installs update manually. Disabling or failing update check does not affect repository work.

## Public platform scope

- macOS Intel x64 and Apple Silicon arm64 are only v0.1.3 public targets.
- Windows compatibility remains separate and does not produce v0.1.3 public artifact.
- Linux is out of scope.

## Preview maturity

- Release is not stable GA or production-readiness claim.
- Third-party integrations may require provider credentials, service availability, and provider-side configuration.
- Cloud-backed agent work requires valid Rainy API key; local repository state remains available when cloud service is unavailable.
- Exact feature outcome depends on workspace policy, repository trust, approvals, available scripts, and validation evidence.

## Telemetry

Telemetry is off by default. Opt-in delivery is best-effort; collector failure does not block product function. Users can disable it under **Settings → Privacy → Product telemetry**.

## Evidence boundary

Assistant text does not prove work succeeded. Missing, skipped, unavailable, cancelled, partial, failed, or stale checks remain non-passing evidence states in Ship Proof.
