# MaTE X v0.1.3 Release Evidence Contract

This tracked document defines required evidence. It is not proof that current checkout passed.

Authoritative evidence is generated by `.github/workflows/build.yml` only after exact commit passes source gate and both native macOS package jobs. Workflow artifact is also named `v0.1.3-release-evidence.md` and must contain actual values, not placeholders or copied v0.1.2 results.

## Required identity

- Exact 40-character commit SHA.
- GitHub Actions run URL and generation timestamp.
- Release label: unsigned macOS Public Preview.
- Publication state: disabled, draft, or prerelease.

## Required command results

Evidence must list pass/fail result for:

```bash
bun install --frozen-lockfile
bun run check:deprecated
bun run lint
bun run typecheck
bun run test:all
bun run verify
bun run verify:release
git diff --check
```

It must include exact test pass/fail count from current `test:all` log.

## Required package evidence

For Intel x64 and Apple Silicon arm64 independently:

- native runner architecture;
- native dependency load result;
- packaging result;
- ASAR purity result;
- packaged E2E result, including black-box startup;
- artifact filenames;
- SHA-256 checksums.

## Required unresolved risks

At minimum for v0.1.3:

- artifacts unsigned and not notarized;
- Gatekeeper explicit approval required;
- native silent auto-update disabled;
- Windows and Linux excluded from public release.

## Truth rule

If exact workflow artifact is absent, incomplete, from another SHA, or any required job failed, release is not proven and verdict cannot be `GO`.
